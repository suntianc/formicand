# 共享桌面页面按宿主能力和执行节点能力工作

设置页和会话页共用一份 DOM。窗口策略为 macOS 选择 inset、Windows 选择 overlay、Linux 选择原生标题栏。preload 将布局语义交给页面，样式按标题栏模式、系统按钮位置与全屏状态分配安全区及拖拽带。

宿主进程通过可信窗口 IPC 提供应用版本、窗口材质、文件打开方式和实际可用的原生功能。窗口访问权限归执行节点，页面切换连接时从目标后端读取状态。桌面凭据留在宿主，Linux 缺少可用系统密钥库时将当前会话令牌保存在内存，并提示重启后需要重新授权。

安装包在目标操作系统原生构建。公开 Beta 的安装更新采用手动覆盖，发布记录按各版本实际通过的安装、签名和升级验收声明支持范围。配置入口与命令见[跨平台行为](../development.md#跨平台行为)和[打包和发布](../development.md#打包和发布)。
