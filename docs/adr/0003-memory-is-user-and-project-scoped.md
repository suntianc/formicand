# 跨会话记忆分用户级与项目级，索引由程序生成

Main 要跨会话记住人和项目的约定，但这些内容既不该写进用户仓库，也不该每轮把全文塞进提示词。决定：记忆分 `user`（跟着人跨项目）和 `project`（只属于一个项目）两级；每条记忆是一个带 frontmatter 的 Markdown 文件，类型为 `user`、`feedback`、`project`、`reference`；Main 按作用域直接写入，不问用户；子代理没有记忆；用户可以在设置里查看、修改、删除，或关掉某个项目的记忆。每轮注入的是程序从文件生成的索引（名称、描述、类型），所以索引不会和存储漂移，正文由 Main 按需读取。记忆放在 Formicand 的数据目录，不进用户仓库。实现见 [记忆存储](../../src/runtime/memory-store.ts) 与 [记忆工具](../../src/runtime/memory-tool.ts)；改动存储布局要迁移已有记忆文件。

状态：生效。
