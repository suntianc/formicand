# 换窗交接同时带模型总结和原始记录

上下文快满时 Formicand 换窗，而不是让会话跑到溢出：交接页里有模型对将要离开的窗口写的总结，也有程序按固定预算带过去的原始记录——最近的对话、开发与票的进展、工作草稿、会话笔记、未结束的提问和后台任务。只留模型写的摘要时，早先定下的约束、试过不行的办法和具体报错会被压成一两句话甚至消失，之后 Main 只能凭摘要继续；原始记录保住确切措辞，总结保住线索，两者缺一都可能丢规矩。真正溢出时没有余量再请求总结，交接只剩记录。实现见 [上下文窗口](../../.pi/runtime/context-windows.ts) 与 [换窗交接](../../src/runtime/session-handoff.ts)：交接写成一条持久压缩记录，升级后恢复的旧会话按它继续，改变格式要保证旧记录仍能读。取舍的理由与实测原文见 `git show 75b62015:docs/memory-and-compaction-design.md` 第一节、第三节与第七节。

状态：生效。
